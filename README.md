# pelusa.app

Сайт приложения Pelusa. Статика: GitHub Pages отдает файлы из корня как есть.

## Как устроено

- `src/pages/` – шаблоны страниц, `src/partials/` – шапка, подвал, `<head>`.
- `src/i18n/<язык>.json` – все тексты. Язык, у которого нет ключа, берет английский (сборка об этом пишет).
- `src/legal/<страница>.<язык>.html` – юридические тексты. Если файла для языка нет, берется файл его `_base` (es-419 → es), а если нет и его – ссылки ведут на английскую версию. Так же подбираются OG-картинки (`images/og/og-<язык>.jpg`) и постеры (`images/posters/<имя>-<язык>.webp`).
- `media/<слот>-<ios|android>-<язык>.{mp4,webm,webp}` – ролики приложения. Нет своего языка – берется база, потом английский; нет версии для платформы – другая. Ролик V1 заменяет прототип телефона на первом экране, V7 – карточку с годами в «Ностальгии». Убрать ролики = удалить файлы и пересобрать. Формат: 600 px в ширину, 30 кадров/с (телефон на странице не шире 300 px). Ролик грузится, когда до блока меньше 300 px и сама страница уже загружена, до этого виден постер.
- Число языков в строке платформ считается по основе кода: es-419, fr-CA и pt-PT – варианты, а не отдельные языки.
- `src/config.json` – ссылки на сторы, соцсети, цифра для полосы «20 минут», список языков сайта и приложения.
- `tools/build.mjs` – собирает `index.html`, `/<язык>/…`, `/get/`, `404.html`, `sitemap.xml`, `lang.js`.
- `script.js`, `style.css`, `images/`, `fonts/`, `sounds/` – общие файлы.

Готовые HTML не править руками: их перезапишет сборка.

## Запуск

```bash
node tools/build.mjs
python3 -m http.server 8766
```

Открыть http://localhost:8766/ (английский), `/ru/`, `/es/`.

## Новый язык

1. Добавить `src/i18n/<код>.json` (можно начать с `"_base": "<код>"` и переопределить только отличия).
2. Добавить язык в `locales` в `src/config.json`. Если `hreflang` не код страны (как `es-419`), перечислить страны в `hreflangAlso`. Короткая подпись на кнопке языка – `short` (иначе код заглавными).
3. Юридические тексты – по желанию: `src/legal/privacy.<код>.html` и т. д.
4. `node tools/build.mjs`.

## Сторы

Ссылки на сторы – `stores.ios` и `stores.android` в `src/config.json`, после правки пересобрать. QR (виден только на компьютере) ведет на `/get/`: телефон сразу уходит в свой стор, компьютер видит кнопки. Пока ссылки для стора нет, его кнопка на сайте ведет на `/get/`, а телефон этой платформы видит там «Pelusa скоро в App Store» (или «…в App Store и Google Play», если ссылок нет совсем).

Метка источника: `pelusa.app/?src=yt-ru-01` или `pelusa.app/get/?src=…` – уходит в ссылку стора (`referrer` для Google Play, `ct` для App Store при заданном `iosProviderToken`).

## Шрифты и иконки

Onest и Unbounded (OFL, лицензии в `fonts/`), иконки – Material Symbols Rounded (Apache 2.0) и значки брендов Font Awesome Free (CC BY 4.0) в `images/icons.svg`. Сторонних запросов у сайта нет, CSP в `src/partials/head.html` это закрепляет.
